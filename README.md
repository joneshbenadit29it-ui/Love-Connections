## 💕 The Vision: Human Heart meets High Voltage

> *"Electrons flow where potential demands it; human hearts connect where passion drives it."*

**Love Connections** bridges the gap between human creativity and electrical engineering. Just as two souls complete a circuit, this interactive web simulator allows you to wire components, visualize real-time waveforms, and feel the spark of creation through an intuitive, modern UI.

---

## ⚡ Sparking Features

* **💘 Dynamic SVG Wiring:** Seamlessly attach nodes with fluid, vector-based connections that feel as natural as drawing a heart line.
* **💓 Equal-Flex Right Inspector Panel:**
  * 🎛️ **Component Inspector:** Tweak resistance, capacitance, and voltage in real time to find the perfect resonance.
  * 📉 **Pulse Oscilloscope:** Live waveform visualizers capturing the heartbeat ($\sin(\omega t)$) of your custom circuit loops.
  * 💌 **Founder Profile:** Embedded author spotlight celebrating the creator behind the simulator.
* **⚡ `CircuitEngine` Core:** A custom JavaScript math engine performing nodal calculations at lightning speed.
* **💬 Event Console:** Terminal logging for step-by-step tracing, voltage metrics, and system diagnostics.

Make sure **Node.js** is installed on your computer.

```bash

# 2. Enter the directory
cd Love-Connections

# 3. Install packages
npm install

# 4. Run the simulator
npm start
